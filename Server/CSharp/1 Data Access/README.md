# 1 Data Access — Server (C#)

These workshops demonstrate how to build OPC UA servers with the PLCcom Server SDK.

| # | Workshop | What you will learn |
|---|----------|-------------------|
| 11 | Simple Server | Create a basic server with variables (Temperature, Pressure, RPM, etc.) |
| 12 | User Authentication | Add username/password and certificate-based authentication |
| 13 | Methods | Expose callable methods in the address space |
| 14 | Variables and Arrays | Create variables with various data types and arrays |
| 15 | Custom Types | Define and expose custom structured data types |
| 16 | Multiple Namespaces | Organize nodes across multiple namespaces |
| 17 | Dynamic Nodes | Create and remove nodes at runtime |
| 19 | Advanced Server | Advanced server configuration and features |

**Default endpoint:** `opc.tcp://localhost:48410` and `opc.https://localhost:48411`
