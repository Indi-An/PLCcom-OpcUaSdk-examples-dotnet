# 2 Data Access – Examples

This folder contains examples for reading, writing and monitoring OPC UA data.
Each subfolder is a standalone sample project.

---

## Recommended order

### 21_DA_Read_Write_by_NodeId
Read and write variable values using NodeIds.

### 22_DA_Read_Write_by_Path
Read and write variable values using browse paths.

### 23_DA_Monitoring_Items
Subscribe to data changes using MonitoredItems and Subscriptions.

### 24_Simple_Method_Calls
Call OPC UA server methods with simple input/output arguments.

### 25_Advanced_Calls_with_Structs
Call OPC UA server methods passing complex structured data types.

### 26_Read_Attributes
Read node attributes (DataType, AccessLevel, Description, etc.).

### 27_Registered_Read_Write
Use registered nodes for optimized repeated read/write operations.
